# NASA Sources Used by ECHOES

These are the primary NASA-linked resources included in the website. Each mission record opens its source in a new browser tab. We used the challenge-provided NASA mission resources where available, plus directly related official NASA pages for the remaining items.

## Main archive resources

- NASA Space Science Data Coordinated Archive: https://nssdc.gsfc.nasa.gov/
- Apollo lunar landing site table (NSSDCA): https://nssdc.gsfc.nasa.gov/planetary/lunar/apolloland.html
- NASA Viking project: https://science.nasa.gov/mission/viking/
- NASA International Laser Ranging Service (Apollo reflectors): https://ilrs.gsfc.nasa.gov/missions/satellite_missions/current_missions/ap11_reflector.html
